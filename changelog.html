Changelog

0.27 — August 3, 2026

  • Fixed a crash switching to the CSD matrix plot with no channels selected.
  • A legend too big for the space it sits in is now cropped instead of going blank — a single over-long channel name used to leave an empty legend box, most visibly in the Time / PSD / Histogram view.

0.26 — August 2, 2026

  • Fixed the harmonic-cursor suppression on frequency plots so it uses a fixed pixel spacing instead of scaling with plot width — it was tripping inconsistently depending on how wide the plot was.

0.25 — August 2, 2026

  • Added a "Clear Recent Files List" item to the File menu.

0.24 — August 1, 2026

  • CSV files no longer list a redundant straight-line time column as a plottable channel.

0.23 — August 1, 2026

  • Fixed the harmonic cursor on frequency plots (PSD/CSD) so it displays correctly when zoomed in away from 0 Hz.

0.22 — August 1, 2026

  • Middle-mouse-button panning now redraws the plot live while you drag, instead of freezing until you let go.

0.21 — July 31, 2026

  • Added data-quality indicators — NaNs, infinities, huge values, subnormal values, and dead channels are now flagged directly on each channel in the file tree, with a tooltip giving the full breakdown.

0.20 — July 29, 2026

  • PlotIt now remembers recently opened files, and reopens to the folder and file type you last used.

0.19 — July 28, 2026

  • Added on-plot markers for NaN and infinite values, with a toggle to hide them.

0.18 — July 28, 2026

  • Refreshed the plot toolbar icons.

0.17 — July 27, 2026

  • Added a legend visibility toggle.
  • Much faster rendering on large files.
  • Fixed numerous crashes on files containing NaN, infinity, or extreme values.

0.16 — July 11, 2026

  • Added Overlay, Stacked, and Stacked-by-Unit plot layouts.

0.15 — July 9, 2026

  • Added a second Y-axis for channels on very different scales.
  • Various histogram and cursor fixes.

0.14 and earlier — June 24, 2026 and before

  • Initial format support (RPC3, PLT, fstrm, CSV) and stability work.
